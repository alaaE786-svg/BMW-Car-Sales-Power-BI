## Overview

This project is an interactive Microsoft Power BI report focused on BMW car sales data. It includes a home page and dedicated report pages for selected BMW models, including **X3, X6, M3, M5, i8, and 3 Series**.

The report is intended to help users explore vehicle-related data and review model-specific information in a visual, dashboard-based format.

## Report Pages

- **Home** — report landing page.
- **X3** — model-focused report page.
- **X6** — model-focused report page.
- **M3** — model-focused report page.
- **M5** — model-focused report page.
- **i8** — model-focused report page.
- **3 Series** — model-focused report page.

## Tools

- **Microsoft Power BI Desktop** — report viewing and development.
- **Power Query / DAX** — may be used for transformation or calculations where present in the report.

## How to Open

1. Download `pro.pbix` from this repository.
2. Open it with Microsoft Power BI Desktop.
3. If Power BI requests access to a data source, follow the prompts only if you have permission to access that source.
4. Explore the report pages and available interactions.

## Notes

- This repository documents the report structure; it does not claim specific sales findings or KPI values that have not been independently verified.
- Data refresh may depend on the original data source and its availability.
- Before sharing publicly, confirm that the report and its underlying data are permitted for public distribution and do not contain confidential information.
